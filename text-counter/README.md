# Text Counter Chrome Extension

A comprehensive text statistics tool that provides real-time analysis of your text.

## Features

- **Character Count** - Total characters and without spaces
- **Word Count** - Total words and average word length
- **Sentence Count** - Detects sentences using punctuation
- **Paragraph Count** - Counts paragraphs based on line breaks
- **Line Count** - Number of lines in the text
- **Reading Time** - Estimated reading time based on 200 WPM
- **Speaking Time** - Estimated speaking time based on 130 WPM
- **Page Count** - Estimated pages based on 250 words per page
- **Reading Level** - Flesch-Kincaid grade level analysis
- **Character Breakdown** - Letters, digits, and special characters
- **Word Frequency Analysis** - Top words and frequency distribution
- **Character Frequency** - Most used characters in the text
- **Reading Level Progress bar** - Visual indicator of text difficulty

## Real-Time Updates

All statistics update in real-time as you type or paste text.

## Usage

1. Click the Text Counter extension icon in Chrome
2. Type or paste text in the textarea
3. Stats panel updates automatically with:
   - Character count (with/without spaces)
   - Word count and average length
   - Sentence and paragraph count
   - Reading and speaking time estimates
   - Reading level (Flesch-Kincaid)
   - Detailed breakdown (letters, digits, special chars)
   - Word and character frequency charts

## Export

Click the "Export" button to download a comprehensive statistics report as a text file.

## Keyboard Shortcuts

- **Ctrl+L** - Focus the text area
- **Ctrl+Shift+C** - Copy text to clipboard

## Permissions

The extension uses:
- `activeTab` - Access active tab for text analysis
- `storage` - Save user preferences
- `scripting` - Inject analysis scripts into web pages

## Development

Built with modern web technologies:
- HTML5 semantic structure
- CSS3 dark theme with glassmorphism effects
- Vanilla JavaScript modular architecture
- Canvas-based charting for visual analytics
