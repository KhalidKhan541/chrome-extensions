# Page Archiver

A Chrome extension for saving web pages for offline reading.

## Features

- **Full Page Save** - Complete HTML with styles and images
- **Screenshot** - Capture visible page as PNG
- **Text Only** - Extract clean text content
- **Reading Mode** - Distraction-free article view
- **Search** - Find saved pages quickly
- **Export/Import** - Backup and restore your archives
- **Auto-save** - Automatically save pages (optional)
- **Storage Management** - Monitor and clean up storage

## Installation

1. Open `chrome://extensions/`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select the `page-archiver` folder

## Usage

1. Click the extension icon on any page
2. Choose a save type (Full, Screenshot, Text, Reading)
3. Click **Save Page**
4. Browse saved archives in the popup
5. Click the eye icon to view saved content

## Settings

- **Auto-save** - Save every page automatically
- **Storage limit** - Max storage for archives
- **Auto-cleanup** - Remove old archives automatically
- **Default save type** - Preferred save format

## Permissions

- `storage` - Save archives locally
- `activeTab` - Access current page
- `tabs` - Get tab information
- `downloads` - Download saved content
- `scripting` - Extract page content
