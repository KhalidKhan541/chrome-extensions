# Chrome Extensions Collection

A comprehensive collection of 20 Chrome browser extensions built with Manifest V3.

## Extensions

### Productivity
| Extension | Description |
|-----------|-------------|
| **AI Writer** | Grammar checker, tone analyzer, text improvements |
| **Quick Notes** | Floating markdown notepad across all pages |
| **Session Manager Pro** | Save/restore tab sessions with tree view |
| **Focus Zone** | Pomodoro timer with website blocker |
| **Expense Tracker** | Personal finance tracking with dashboard |

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable **Developer mode** (toggle in top right)
3. Click **Load unpacked**
4. Select the extension folder

## Technical Details

- **Manifest Version:** V3
- **Browser:** Google Chrome
- **Code Style:** ES6+ JavaScript, no external dependencies
- **All extensions work offline** (no API keys required)
