# accessibility-auditor

Chrome extension for accessibility auditing and WCAG compliance checking.

## Features

- Accessibility analysis
- WCAG compliance checking
- Color contrast verification
- Keyboard navigation testing

## Installation

1. Open `chrome://extensions/`
2. Enable Developer mode
3. Click "Load unpacked" and select the `accessibility-auditor` folder

## Development

```bash
npm install
npm run lint
npm run test
npm run build
```
